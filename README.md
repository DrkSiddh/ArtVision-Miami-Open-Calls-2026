# ArtVision Miami Art Week Opportunities

Running database of free and low-cost opportunities to exhibit digital or physical art during Miami Art Week (especially Web3/crypto related), plus conversational narrative scripts for the ArtVision podcast special segment.

## Files
- `narrative_script.md`: Coffee-chat style script for podcast.
- `opportunities_database.json`: Searchable entries (filter by keywords like "MIAMI", status "open", deadline).

## Usage
Search the JSON for open opportunities. Update daily with new finds. Prefer free entry; note fees only if highly prestigious with clear value.

Miami Art Week 2026: ~November 30 – December 6.
