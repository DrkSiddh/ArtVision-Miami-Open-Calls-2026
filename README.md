# ArtVision Miami Art Week Opportunities

Running, searchable database + conversational narrative scripts for free (or justified-fee) opportunities to exhibit digital or physical art during Miami Art Week, with special attention to web3/crypto-related organizations and curators.

## Voice
Encouraging, uplifting, casual-but-authoritative (friend over coffee), never punching down. For the ArtVision brand podcast special segment.

## Files
- `narrative_script.md` — Podcast-ready conversational script.
- `opportunities_database.json` — Structured entries. Search by keywords (e.g. "MIAMI"), filter by status: "open", deadline, etc.

## How to use the database
Load the JSON. Filter where `status === "open"` and keywords include your search term. Each entry has clear deadline, URL, questions count, receipts required, fee (and reason if any), exhibition details.

Opportunities are tracked until they expire so daily 1–3 new listings can be surfaced.
